# Журнал редакций · Changelog

## 1.2 — 2026-10-15
- Казахский языковой пакет: открытый пакет kk-KZ для Joomla 6 принят в официальный каталог языковых пакетов Joomla (с версии 6.2.0.1) и ставится из установщика языков самой Joomla. Исправлены резюме, глава «Русская и казахстанская экосистема», рекомендации; белое пятно М-06 закрыто. Запасной язык ru-RU с 6.2 описан как средство для строк сторонних расширений.
- Лонгрид: тот же раздел «Казахстан» и симулятор запасного языка — строки ядра теперь переведены, непереведёнными показаны строки стороннего расширения.
- Источники: добавлены каталог Joomla! 6 — Kazakh и репозиторий пакета; список перенумерован по первому упоминанию (95).
- Главная копия на webmarka.kz переехала на адреса без `.html`: `/doklad/` и `/longread/`; canonical обновлены.

- Источники перенумерованы по первому упоминанию (93).
